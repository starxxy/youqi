# 有期 · 第一轮 UI 设计

状态：需求已确认，当前交付可交互 UI 选型稿；用户选定方案后进入正式 APP 开发。

## 第二轮：适度液态玻璃

三套布局叠加独立材质层：浅色使用轻透光与柔和蓝/紫环境色，深色使用克制的暖色反光。卡片采用半透明、背景模糊与双层边缘高光；底部导航改为可透出滚动内容的悬浮玻璃，改期弹层与桌面侧栏使用相同语义材质。

外观页可单独关闭液态玻璃，与明暗主题独立保存。低兼容性浏览器及减少透明度偏好会回退为实色表面。模糊、透明度与饱和度已加入 token 和跨端主题接口；原生实现时需结合实际设备性能与系统能力调整。

逾期色阶与改期标识保持实色，确保等级和次数清晰。滚动内容底部留足空间，悬浮导航不会挡住最后一项。原版可在 archive/有期-UI设计-原版.html 对照查看。

## 设计方向

| 方案 | 视觉与布局 | 主要适用场景 |
| --- | --- | --- |
| A 澄明 | 雾白背景、钴蓝操作色、紧凑列表、明确分组；先看未完成事项，再安排时间 | 每天任务较多，希望快速记录、处理逾期 |
| B 时序 | 浅紫背景、靛紫操作色、连续时间刻度；当前时间与空闲段清晰可见 | 作息固定，需要按时间段执行 |
| C 聚焦 | 石墨深色、柔杏操作色、大字号当前任务；保留待处理队列 | 任务容易分散注意力，倾向一次处理一件 |

三个方向使用同一份业务数据与规则，区别不只是颜色。清爽列表、时间轴、专注台分别改变首页的信息优先级。为避免变成相同卡片换色，列表方案强调行分隔，时间方案强调连续刻度，专注方案强调单一当前任务。

## 基础设计规范

- 中文：优先 Microsoft YaHei UI / PingFang SC，时间数字使用系统无衬线等宽数字。
- 手机基准：390 × 844；主要触控目标不小于 44 px；支持窄屏滚动。
- 文字：页面标题 27–30 px；任务标题 15–17 px；正文 13–14 px；辅助文字 11–12 px。
- 对齐：文字左对齐；时间、状态和操作使用稳定列宽；底部四个主入口一致。
- A：背景 #F5F7FB、表面 #FFFFFF、正文 #172338、主色 #315BD6、弱色 #E8EEFF。
- B：背景 #F4F2FA、表面 #FFFFFF、正文 #28233C、主色 #7155BB、弱色 #EDE6FA。
- C：背景 #20252C、表面 #2B3139、正文 #F4F1EB、主色 #F1BE83、弱色 #463C32。
- 不用颜色单独传达状态；逾期始终同时显示天数与等级，改期始终显示次数。
- 减少动态装饰；交互反馈遵循系统减少动画设置。

## 页面范围

每个方案包含：今日、日程、闹钟、排班、任务详情、到期处理、外观、同步与设备。另提供桌面三栏适配预览。

## 交互与示例

- 示例日期固定为北京时间 2026-10-11，方便稳定对比；不是实时账户数据。
- 任务完成、增加任务、改期、事件时间编辑、多提醒增删、闹钟开关、排班编辑、换肤和设备提醒偏好可交互。
- 示例状态保存到当前浏览器 localStorage；可通过设计台“重置演示”恢复。
- 操作是浏览器原型演示，不申请系统闹钟权限，不发出真实闹铃，不连接同步服务器。
- 无截止日期时逾期等级为 0；截止日期当天未逾期；次日等级 1，第 7 天及以后等级 7。
- 继续延后不修改截止日期；改为未来截止日期后当前逾期归零，同时保留原始日期、改期次数和历史。
- 改期色相循环切换，逾期深浅独立显示。色相循环后仍用次数区分。
- 待办截止日期与某天时间安排分别存储；仅改截止日期不会擅自移动当天时间段。移动事件开始/结束时间时关联提醒随之计算。
- 闹钟规则分为：一次、按星期、每 N 天、时段内周期、N 天排班；贪睡是响铃后的独立行为。

## 跨端与换肤扩展

详见 ../contracts/README.md。UI 使用语义主题变量，业务对象不保存 CSS 色值。同步、设备、提醒调度通过平台无关接口描述，为 Android、Windows、macOS 保留实现空间；当前没有实现远程同步或原生调度。

## 选型

可选择 A / B / C，或指定混合，例如“A 的任务列表 + B 的日程 + C 的深色皮肤”。首轮选择布局方向，后续再精调颜色、密度与动效。
