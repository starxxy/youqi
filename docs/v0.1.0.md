# 有期第一版归档说明 · v0.1.0

归档日期：2026-10-12。此标签保存第二版修改前的源码、UI 原型、自动化测试、说明和实际交付安装包；已知问题如实记录，不在第一版标签中混入修复。

## 产品目标与已实现功能

有期以安卓手机为第一阶段，后续考虑 Windows / macOS 与手机同步。第一版离线工作，三套界面使用同一份数据：A 澄明以待办分组为主，B 时序以时间轴为主，C 聚焦以当前事项为主。提供明暗主题与可关闭的液态玻璃材质。

待办可以持续显示直到完成，也可设置每日、指定星期或每 N 天重复，各次完成独立记录。开始日期、预计自然日天数与截止日期分开保存；按天数填写截止日期时开始当天算第 1 天。截止次日起逾期每天升一级，最高 7 级，实际逾期天数继续累计。继续延后保留截止日期；重新设定截止日期保存旧日期、新日期、改期序号和历史，改期标识换色。

每日规划保存事件开始与结束时间，支持跨午夜；一个实例可规划到不同日期，每天一个独立时间段。相对提醒可锚定开始或结束，设置提前、准时或延后，并可添加多条。调整事件时间后重新计算提醒。

独立闹钟支持一次、每天、指定星期、间隔 N 天和时段内周期。排班可设 1—31 天，每天多个闹钟，空白为休息；临时调整覆盖某一天，不移动后续循环。铃声、音量、振动、单次响铃时长、贪睡与自动重响均有设置。还有专注倒计时、响铃记录和 JSON 备份恢复。

## 源码组织与技术选型

- `design/` 与根目录 HTML：早期交互设计稿，固定示例日期，没有真实系统闹钟。
- `mobile/lib/core.dart`：任务模板与实例、逾期/改期、本地 JSON 持久化、稳定 ID、删除标记、变更队列和同步传输接口。
- `mobile/lib/ui.dart` / `editors.dart` / `skins.dart`：三套布局、编辑流程、权限入口、备份与可注入的皮肤接口。
- 原生 Kotlin `RuleEngine`：周期、轮班、跨午夜和时区规则。
- `AlarmHub`：系统精确闹钟登记、触发去重、重启/时区/权限恢复时对账。
- `AlarmService`：前台音频、振动、超时、贪睡与同时到达队列。
- `AlarmActivity`：第一版原生响铃处理页。
- `MainActivity`：Flutter 通道、系统权限、铃声选择与备份文件选择。
- `contracts/`：未来桌面端、同步和换肤契约；手机当前数据映射以 `mobile-v1.md` 为准。

工具版本为 Flutter 3.24.5 / Dart 3.5.4、JDK 17、SDK 35、AGP 8.5.2、Kotlin 1.9.24、Gradle 8.9。Android minSdk 26、targetSdk 35，包名 `cn.youqi.youqi`。数据存储在 APP 私有目录的 SharedPreferences JSON 中；当前没有账号或网络服务。

## 第一版验证与实际反馈

开发环境自动验证：Flutter analyze 无问题；Flutter 11 项测试和 Kotlin 12 项周期测试通过；Android lint 为 0 错误、13 警告；APK 签名与 SHA256 校验通过。页面截图为 Widget 渲染，不是真机截屏。详细范围见 `mobile/验证记录.md`。

用户于 2026-10-12 已安装并确认能实际响铃，同时反馈：

1. 响铃后点击 APP 图标没有进入关闭闹铃界面，需要借助设置才能关闭。
2. 需要与设计稿一致的响铃页，直接关闭或延后 5 / 10 分钟；每次延后后，下次界面颜色加深一级。
3. 不喜欢钟表式时间选择，要求改为小时/分钟上下滚轮，逐档轻微振动。

代码检查发现 MainActivity 没有把启动或恢复路由到正在响铃的 AlarmActivity，前台响铃也没有主动显示处理页；第一版只配置通知全屏入口，不能覆盖用户报告的进入路径。第二版将修复这些入口与交互；第一版标签保持原样。

锁屏、熄屏、重启恢复及厂商后台限制没有完成开发机真机验收；用户报告仅证明安装与响铃实际发生。系统强制停止后需重新打开恢复未来调度，错过的提醒不会补响。

## 同步和换肤扩展

已实现 `SyncTransport` 与 `LocalRepository` 边界，以及 mutationId、baseRevision、deviceId、outbox、tombstone。`NotConnectedTransport` 明确报未配置服务，不会伪装同步成功。未来需补认证、服务端版本与冲突处理、桌面存储/调度适配、设备响铃策略和铃声资源映射。

已实现 `SkinProvider` / `SkinTokens` 注入，布局选择与业务数据分离。三套界面共用实例、改期与闹钟数据；新增皮肤无需改变任务计算。
