## 三套设计

| 方案 | 首页重点 | 默认外观 |
| --- | --- | --- |
| A 澄明 | 待办分组与逾期处理 | 浅色钴蓝 |
| B 时序 | 连续时间轴与空闲时段 | 浅色紫 |
| C 聚焦 | 当前任务与后续队列 | 深色柔杏 |

顶部页面选择器可以同时切换三套方案的今日、日程、闹钟、排班、任务详情、到期处理、外观和同步。各手机底部导航与任务按钮可独立操作。顶部可切换桌面适配并选择方案。

## 可操作的交互

添加待办及时间段；标记/撤销完成；修改事件时间并自动调整相对提醒；增删多个提醒；重新设定截止日期并保存改期次数/历史；闹钟开关及自定义规则；排班修改及当天例外；明暗换肤；按设备保存响铃/通知/静默偏好。

界面数据固定在 2026-10-11 的示例场景，本机浏览器保存交互状态，“重置演示”可恢复。没有真实闹铃、账号登录或远程同步。重复任务生成、后台调度和跨端冲突引擎属于正式 APP 开发范围，原型仅演示其界面。
